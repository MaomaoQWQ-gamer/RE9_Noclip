# 🚀 RE9 NoClip Mod

> A professional Lua script for [REFramework](https://github.com/praydog/REFramework) that enables NoClip functionality for Resident Evil 9.

## 🎥 Preview

https://github.com/user-attachments/assets/dda9607f-0503-48ab-b238-92cb6ca895bd



## ✨ Features
* **NoClip Movement**: Fly through the environment with customizable speed and controls.
* **Godmode & Anti-Death**: Built-in protection to prevent game-over states and fall damage.
* **Full UI Integration**: Uses REFramework UI for real-time configuration.
* **Camera Sync**: Teleport the player to the current camera position with rotation sync.
* **Physics Tweaks**: Options to disable collision shake and force ground-keeping to prevent glitches.

## 🕹️ Controls
| Action | Key |
| :--- | :--- |
| **Toggle NoClip** | `F2` |
| **Move** | `W`, `A`, `S`, `D` |
| **Move Up** | `E` |
| **Move Down** | `Q`|
| **Sprint** | `Shift` |
| **Precision Mode** | `Ctrl` |

## 🚀 Installation

### 1. Install REFramework
To use this mod, you must first install **REFramework**. You can download it here:
[https://github.com/praydog/REFramework/releases](https://github.com/praydog/REFramework/releases)
*(Make sure to download the latest release for Resident Evil 9).*

### 2. Install the Lua Mod
1. Extract REFramework into your game installation folder.
2. Navigate to your game directory: `.../Resident Evil 9/`.
3. Open the `reframework` folder. If the `autorun` folder does not exist inside it, **create a new folder** and name it `autorun`.
4. Drop the `re9_noclip.lua` file into this path: `.../Resident Evil 9/reframework/autorun/`.
5. Launch the game, press `Insert` to open the REFramework menu, and you will find the mod settings under **"Script Generated UI"**.
